## 1. Set up Docker’s apt repository

<aside>
💡

과정 요약

1. **시스템 준비:** 최신 패키지 목록을 업데이트하고, HTTPS 통신과 데이터 전송에 필요한 도구들을 설치합니다.
2. **GPG 키 설정:** Docker 저장소의 신뢰성을 확인하기 위해 GPG 키를 다운로드하고 올바른 권한으로 설정합니다.
    - Docker 저장소에서 제공하는 소프트웨어 패키지의 출처와 무결성을 보장하기 위해 사용되는 디지털 서명 키
3. **저장소 추가:** Docker 저장소 정보를 apt 소스에 추가하여, 이후 Docker Engine을 설치할 때 해당 저장소에서 패키지를 가져올 수 있도록 합니다.
4. **최종 업데이트:** 추가한 저장소의 패키지 목록을 포함하도록 시스템의 패키지 목록을 다시 업데이트합니다.

이 과정을 완료하면, `sudo apt-get install docker-ce docker-ce-cli containerd.io` 등의 명령어를 통해 Docker Engine을 설치할 수 있습니다.

</aside>

```bash
# Add Docker's official GPG key:
# GPG 키 설정 및 저장소 준비

# 시스템 패키지 목록 업데이트
sudo apt-get update

# 필수 패키지 설치 
# ca-certificates: SSL 인증서를 관리하여 HTTPS 연결 시 보안 검증을 가능하게 함.
# curl: URL을 통해 데이터를 전송받거나 다운로드할 때 사용하는 도구.
sudo apt-get install ca-certificates curl

# /etc/apt/keyrings 디렉토리 생성. 이 디렉토리는 Docker의 GPG 키를 저장할 위치.
# -m 0755: 디렉토리의 권한을 설정, -d: 디렉토리를 생성하는 옵션
sudo install -m 0755 -d /etc/apt/keyrings

# Docker의 공식 GPG 키 다운로드하여 /etc/apt/keyrings/docker.asc 파일에 저장.
# -f: HTTP 요청 실패 시 에러를 발생. -s: 진행 상황을 출력하지 않음. -S: 에러 발생 시 메시지 출력
# -L: 리다이랙션이 있을 경우 따라감. -o: 결과를 지정한 파일로 저장.
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc

# 다운로드한 GPG 키 파일에 대해 모든 사용자에게 읽기 권한을 부여
# apt가 Docker 저장소의 패키지를 검증할 때 필요
sudo chmod a+r /etc/apt/keyrings/docker.asc

# Add the repository to Apt sources:
# apt 소스 리스트에 Docker 저장소 추가
# deb: Debian 패키지 형식의 저장소임을 지정.
# [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc]:
# arch=$(dpkg --print-architecture): 현재 시스템의 아키텍처(예: amd64)를 자동으로 감지.
# signed-by=/etc/apt/keyrings/docker.asc: 이 저장소의 패키지가 지정된 GPG 키로 서명되었음을 지정.
# https://download.docker.com/linux/ubuntu: Docker의 공식 Ubuntu 저장소 URL.
# $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}"):
# /etc/os-release 파일에서 Ubuntu의 코드네임(예: focal, jammy 등)을 추출.
# stable: 안정 채널의 패키지를 사용하겠다는 의미.
# sudo tee 명령어를 사용해 /etc/apt/sources.list.d/docker.list 파일에 저장
# > /dev/null: 터미널 출력 내용 숨김.
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt-get update
```

## 2. Install the Docker packages

- 가장 최신 버전의 Docker 설치 후 run

```bash
# docker-ce: Docker Community Edition을 의미. Docker 데몬이 포함되어 있으며,
# 컨테이너를 실행, 관리하는 핵심 구성 요소
# docker-ce-cli: Docker의 명령어 인터페이스를 의미. 사용자가 터미널에서 Docker 명령어를 입력해 Docker 데몬과 상호작용할 수 있도록 해줌.

sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

## 3. Verify that the installation is successful by running the hello-world image

- Docker 설치가 제대로 되었는지 확인하기 위해 hello-world 이미지 다운로드 후 컨테이너 실행.

```bash
sudo docker run hello-world
```
